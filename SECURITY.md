# Security Policy

The ADLC Manifesto repository is primarily documentation and static website
source, but responsible disclosure still matters.

## Reporting a Vulnerability

Please do not open a public issue for security-sensitive reports.

Send a private report through GitHub's private vulnerability reporting feature
when available, or contact the maintainer privately with:

- a concise description of the issue;
- affected files, pages, or scripts;
- steps to reproduce;
- potential impact;
- any suggested remediation.

## Scope

Security reports are welcome for:

- exposed credentials or secrets;
- unsafe publishing scripts;
- website vulnerabilities;
- supply-chain or dependency concerns;
- misleading security guidance in the documentation.

General editorial suggestions should use normal issues or pull requests.
